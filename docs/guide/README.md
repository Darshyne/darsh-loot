# Guide (source)

Source of the GM guide for containers and traps, in two languages. One Markdown file per page, written to be published as-is to the
GitHub wiki of this repository (page names are file names: `Home`, `Accueil`, `Containers`, `Conteneurs`…), and later turned into an
in-Foundry journal.

- `fr/` — Accueil, Conteneurs, Pieges, Reglages
- `en/` — Home, Containers, Traps, Settings
- `images/fr/`, `images/en/` — screenshots, one set per client language (`.webp`, cropped from a 1876 × 996 Foundry window)

Write each change in both languages. Labels in bold are the exact labels of the interface (`module/lang/fr.json`, `en.json`).
